# Фанты — правда или действие (веб-версия)

Домашняя некоммерческая реплика пати-игры: один телефон по кругу, колесо выбирает игрока,
база из **120 заданий** встроена в приложение и работает офлайн.

## Структура

```
index.html            — единственная страница
css/style.css         — стили и палитры уровней (fun / soft / hot)
js/data.js            ← ВСТРОЕННАЯ БАЗА ЗАДАНИЙ (правь здесь, чтобы добавить свои фанты)
js/app.js             — логика: карусель, игроки, спин, таймер, звук
manifest.webmanifest  — PWA-манифест (установка на главный экран)
sw.js                 — офлайн-кеш
icon.svg              — иконка
```

## Как играть

1. Открой сайт → выбери уровень (свайп: Fun / Soft / Hot) → «Играть».
2. Введи имена игроков (2–12) — они сохранятся в браузере.
3. Жми круглую кнопку — колесо выбирает игрока, дальше «правда» или «действие».
4. Зелёная полоса справа — таймер 60 секунд на выполнение.
5. «Готово! Крутим дальше» → следующий раунд.

Уровень, игроки и звук сохраняются между открытиями (localStorage).

## Как добавить свои задания

Открой `js/data.js`, найди нужный уровень (`fun` / `soft` / `hot`) и допиши строки
в списки `truth` (правда) и `action` (действие). Шаблоны:

- `{name}` — имя выбранного игрока;
- `{other}` — имя случайного другого игрока.

После изменения файлов на хостинге поменяй версию кеша в `sw.js`
(`const CACHE = 'fant-v1'` → `'fant-v2'`), чтобы телефоны подтянули обновление.

## Публикация (бесплатно, 5 минут)

**GitHub Pages:**
1. Создай репозиторий на github.com и загрузи все файлы этой папки.
2. Settings → Pages → Source: `main` branch, `/ (root)` → Save.
3. Через минуту игра будет на `https://<логин>.github.io/<репозиторий>/`.

Открой ссылку с телефона → «Добавить на главный экран» → игра запускается как
приложение, фуллскрин и офлайн.

Альтернативы: Netlify Drop (перетащить папку на netlify.com/drop), Vercel, Cloudflare Pages.

> Локально (файлом, без интернета) тоже работает, но PWA-установка и офлайн-кеш
> активируются только по HTTPS — то есть после публикации.

## Стек

Чистые HTML/CSS/JS, без сборки и зависимостей. Звук генерируется через WebAudio,
вибрация — Vibration API.
