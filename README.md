# Фанты + Продолжи фразу — пати-игры для компании

Домашняя некоммерческая веб-реплика пати-игр. **Две игры в одной:**

1. **Фанты** — правда или действие: колесо выбирает игрока, выбираешь
   «правда» или «действие» (с превью), выполняешь, зал решает —
   «Выполнено» / «Не выполнено». Круги с выбыванием, три уровня
   (Fun / Soft / Hot), **362 базовых задания + 34 в пакетах**.
2. **Продолжи фразу** — отвечай неправильно, но уверенно: пара
   «читает → отвечает» выбирается двумя прокручивающимися столбиками,
   пара прогоняет N фраз, зал ставит оценку 1–5, после круга — итоги,
   последнее место получает наказание. **215 начал фраз** в базе.
3. **Нарисуй по памяти** — командный режим: диктор зачитывает слова
   (темп и пауза настраиваются), все зарисовывают их по номерам на
   бумаге, затем случайные пары «задающий → отвечающий» проверяют
   рисунки: угадал — балл тебе, нет — балл помнящему задающему.
   **236 слов** в 10 категориях (js/draw-memory-data.js).

**Пакеты заданий** (на экране уровней): «У моря зимой» — базовый,
плюс включаемые «Квартирник», «Дача», «Новый год» (в Hot не
подмешиваются — он тематический). **Комбинаторика** действий
(только Fun/Soft, шанс ~20%): 12 объектов × совместимые глаголы ×
4 формата = **112 вариантов**, «без слов» — секретная пантомима
на 2 минуты. Локальные токены {room} и {object} подставляют комнаты
и предметы дома.

Базы встроены (офлайн), свой контент — не нужен.

## Структура

```
index.html            — единственная страница
css/style.css         — стили, палитры уровней, Montserrat встроен (fonts/)
js/data.js            — база фантов (362 задания) + пакеты (34) + токены
js/combo-data.js      — комбинаторика действий (объекты/глаголы/форматы)
js/phrase-data.js     — база начал фраз (215) для «Продолжи фразу»
js/draw-memory-data.js — база слов (236) для «Нарисуй по памяти»
js/draw-memory-core.js — чистая логика режима: выбор слов, пары (алгоритм
                        Куна по шагам), баллы, резерв номеров; тестируется на Node
js/app.js             — логика всех игр
tests/                — node-тесты: counts.js (счётчики), core.test.js (логика),
                        content-check.js (самопроверка контента),
                        draw-memory.test.js (инварианты режима рисования)
manifest.webmanifest  — PWA-манифест
sw.js                 — офлайн-кеш
apple-touch-icon.png  — иконка для iOS (PNG, из icon.svg)
icon.svg              — векторная иконка
```

## Игровые токены (в базах заданий и фраз)

- `{name}`, `{name-acc/dat/inst/gen}`, `{other…}` — имена с падежами;
  склоняет словарь, для латинских ников — апостроф (denplis'а)
- «(благодарен|благодарна)» — формы по полу игрока (М/Ж в списке
  игроков); пол не указан — остаётся со скобками
- `[[таймер N]]` — кнопка запуска таймера на N секунд; если в тексте
  есть «15 секунд» / «2 минуты» / «одну минуту» — кнопка появится сама
- `[[тайно]]` — секретное задание: на экране выбора показывается только
  подпись «Секретный вопрос» / «Секретное действие» — сам текст не виден
  и не озвучивается до выбора; раскрывается только сценарием
  «возьми телефон» на экране задания
- `[[мод:текст]]` — свой модификатор вместо случайного
- `[[без мод]]` — запретить модификатор

## Механики

- Колесо: тап — короткая анимация, свайп — полная с физикой жеста;
  два последних игрока не выпадают подряд
- Круги с выбыванием («Выполнил» — вылетает до следующего круга),
  блиц-круг 3 минуты (включается на экране колеса)
- Модификаторы к действиям (шанс 50%, золотая плашка «Условие: …»)
- Статистика: сводка каждые 3 круга + кнопки на экранах;
  у «Продолжи фразу» — средние оценки по игрокам
- Настройки каждой игры — на её первом экране (у фантов — уровни
  и блиц, у фраз — вопросы и режимы, у рисования — слова/темп/пауза/
  дорисовка); общие — в меню ⋮

## «Нарисуй по памяти» — правила и честность пар

- Настройки: слов от каждого игрока 1–10 (чипы 2/3/4/5 + степпер),
  темп чтения 0.5–1.5× (чипы медленно/обычно/быстро + ползунок),
  пауза между словами 0–3 с, время дорисовки 15/30/45/60 с или без.
  Всего слов и проверок всегда = игроки × слов от каждого.
- Слова произносятся русским голосом системы один раз, на экране —
  только номер и прогресс. Без голоса режим не начинается.
- Пары строит алгоритм Куна по шагам: каждый задаёт ровно выбранное
  число вопросов и отвечает столько же; никто не спрашивает себя;
  направленная пара «А задаёт Б» не повторяется, пока А не спросил
  всех остальных. Пары фиксируются на раунд и показываются по одной:
  «Проверка N из M», следующая — только после зафиксированного исхода.
- Проверка: задающий выбирает номер рисунка (слово скрыто), звучит
  устный ответ, затем «Показать исходное слово» и вердикт — баллы
  отвечающему / задающему / никому. Каждый номер рисунка можно
  проверить только один раз за партию (usedNums, переживает
  перезагрузку); повторное начисление невозможно, результат можно
  отменить с подтверждением — пересмотр остаётся в истории, но номер
  остаётся использованным.
- Незавершённый раунд хранится (fant.dmRound) и открывается в
  безопасной паузе: слова сами не проигрываются. Выход и меню
  останавливают голос и таймеры.

## Процедуры

**Изменение контента** (после любой правки `js/data.js` / `js/phrase-data.js`):
1. `node tests/content-check.js` — самопроверка контент-пака (§5): счётчики,
   дубликаты и похожие формулировки, инвентарь токенов, поцелуи в Soft/Hot,
   легальность таймеров, формат фраз, служебные пометки
2. `node tests/core.test.js` — логика (склонения, пол, комбо, секретные превью)
3. Новые записи: truth кончается «?», токены `{name}/{other…}`, таймеры только
   15/20/30/60/120; если менялся итог — править `tests/counts.js` **и** README
   вместе (тесты уронят рассинхрон)

**Релиз**: версия синхронно в трёх местах (см. «Обновление» ниже), push в
`main` — GitHub Actions задеплоит сам. Изменения только тестов/README версию
не поднимают (в payload приложения они не входят).

## Публикация (бесплатно)

1. Залей в репозиторий на GitHub (все файлы этой папки)
2. Settings → Pages → Source: `main` branch, `/ (root)` — либо
   деплой через GitHub Actions (`.github/workflows/deploy.yml` уже настроен)
3. Игра: `https://<логин>.github.io/<репозиторий>/`

На телефоне: «Добавить на главный экран» — фуллскрин, офлайн,
иконка-корона. Настройки и игроки сохраняются в браузере.

## Обновление (важно!)

Синхронно меняются **три** места:
1. `sw.js`: `const CACHE = 'fant-vNN'`
2. `index.html`: все ссылки `?v=NN` на css/js
3. `index.html`: текст версии на главном экране

SW для страницы — network-first: после обновления кеша достаточно
одного обновления страницы. Проверка: маркер версии на главном экране.

## Стек

Чистые HTML/CSS/JS без сборки. Шрифт Montserrat встроен. Звук —
WebAudio, вибрация — Vibration API, озвучка заданий — системный
речевой синтез. Прокрутка колеса — Web Animations API (нативный,
работает офлайн), при отсутствии — requestAnimationFrame.
