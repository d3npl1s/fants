**Статус:** это ТОЛЬКО предложение. Теги `[[о себе]]` в `js/phrase-data.js` не
проставлены — данные не менялись. Применять список только после явного ОК

показа, озвучки и превью реализует агент `lang.js`/`app.js` (PHRASE-5).

**Ветка:** `agent/auditfix2-content` (база 80a07e3). Объём ревью: все 75
записей `PHRASE.prompts.names` в `js/phrase-data.js`, каждая оценена целиком,
вручную (автоматический список из 22 совпадений не принимался как итоговый).

## Критерий классификации

- **Тег нужен** — фраза обращена к отвечающему во втором лице: «ты / твой /
  твоя / тебе / тебя», формы «вы» (в т. ч. «вы с {other-inst}»), а также
  вокатив «{name},» с содержанием о том же игроке. Такой фразе нужен
  `who = answerer`.
- **Тег не нужен** — фраза о третьем лице: повествование про `{name}` /
  `{name-gen}` / `{name-acc}` / `{name-inst}`, которое отвечающий
  заканчивает как шутку про другого игрока (`who ≠ answerer`).
- Слово «свой» само по себе не признак: в третьем лице это возвратное
  притяжательное («Свой Wi-Fi {name} назвал(а)...» — «свой» = его/её).
- Формы с «(а)» («сказал(а)», «купит», «был(а)») — не признак второго лица,
  если грамматически это третье лицо.

## Итог

**Тег `[[о себе]]` нужен: 25 записей (№ 51–75). Тег не нужен: 50 записей
(№ 1–50).** Блок 51–75 — весь с вокативом «{name},» и обращением к самому
игроку; блок 1–50 — весь про третьих лиц.

## Спорные и проверенные вручную случаи (с обоснованием)

- **№ 26 «Свой Wi-Fi {name} назвал(а)...» — без тега.** Пример из ТЗ:
  «свой» здесь возвратное притяжательное третьего лица (его/её Wi-Fi),
  обращение к отвечающему отсутствует. Тег ставить нельзя.
- **№ 54 и № 61 (формы «вы») — тег нужен.** «если бы вы с {other-inst}...» —
  «вы» относится к {name} (вместе с другим участником), т. е. фраза
  адресована игроку {name}; regex-пропуск из ТЗ подтверждён. При теге:
  `who = answerer`, `other = {other-inst}` — при двух игроках `other`
  станет вторым игроком (согласовано с PHRASE-6).
- **№ 56 и № 67 — тег нужен (regex их не ловил).** Вокатив «{name},» +
  содержание о том же игроке через `{name-gen}` («у {name-gen}», «{name-gen}
  ещё нет на купюрах») — это те «два похожих случая», которые автоматика
  пропустила: технически третье лицо, по смыслу адресовано самому игроку.
  Без тега получилось бы «Даня, если бы у Дани был герб...» в исполнении
  постороннего отвечающего — обращение «висит в воздухе».
- **№ 43 «Если бы {name} был(а) блюдом...» — без тега.** Гипотетическое
  наклонение, но грамматика третьего лица («был(а) блюдом»), шутка
  завершается про выбранного игрока, обращение к отвечающему отсутствует.
- **№ 2, 20, 27, 46, 47 (формы «(а)») — без тега.** «проснул(ся|ась)»,
  «сказал(а)», «выяснил(а)» — третье лицо; суффикс «(а)» не признак
  адресации. № 27 «купит» и № 29 «запретит» — будущее время третьего лица.
- **№ 1 и № 17 ({name-acc}) — без тега.** Косвенный падеж в пассивной
  конструкции («в космонавты не берут», «взяли в сборную») — однозначно
  рассказ о третьем лице.
- **Проверено и не найдено:** прямых повелительных обращений к {name} в
  массиве нет; форм «ваш/ваша» нет; в блоке 1–50 второго лица нет ни в
  одной записи — каждая перепроверена целиком, а не по подстроке.

## Замечание по способу проверки

JS-regex с `\b` неработоспособен для кириллицы (`\b` считается только между
ASCII-словом и не-словом), поэтому «автоматический список совпадений» в
принципе не мог быть надёжным — ревью выполнено чтением каждой записи
целиком, программная проверка использовалась только для вывода нумерованного
списка и контроля распределения вокативов (все записи 51–75 начинаются с
«{name},», ни одна из 1–50 — нет).
